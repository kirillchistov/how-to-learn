# Научиться учиться

Блог о техниках обучения: канон с практическими заметками и радар свежих материалов. Черновики радара не публикуются сами.

## Локально

```bash
npm install
npm run dev
```

Сайт откроется на [http://localhost:3000](http://localhost:3000). В режиме разработки видны и черновики, с пометкой. Обычная сборка показывает только записи со статусом `published`. То же самое делает preview-деплой: черновики видны там и скрыты на проде.

## Радар

Скрипт смотрит Hacker News, RSS Скотта Янга, Кэла Ньюпорта, Farnam Street и The Learning Scientists, плюс узкий запрос arXiv. Он оставляет свежее по теме, вычитает уже сохранённые ссылки и пишет не больше трёх черновиков в `content/radar`.

Ключ кладётся в `.env.local` по образцу `.env.example`.

```bash
npm run ingest -- --dry-run
npm run ingest
```

Без `OPENAI_API_KEY` обычный запуск останавливается и ничего не пишет. `--dry-run` только печатает кандидатов.

Публикация — это правка файла и `status: published`. GitHub Action `.github/workflows/radar.yml` раз в сутки открывает pull request с черновиками, если в секретах репозитория задан `OPENAI_API_KEY`.
